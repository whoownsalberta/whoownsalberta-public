# WhoOwnsAlberta public releases & open data

This repository is the public release boundary and open-data distribution point
for **WhoOwnsAlberta.info**. GitHub Pages deploys only from protected `main`
through the `deploy-pages` workflow (`https://whoownsalberta.github.io/whoownsalberta-public/`).
The `public-artifact` job checks every PR and is required for merging; `main`
also requires an independent approving review.

## Mining the public data

Every published `wiki-v1` release can include machine-readable open-data exports
under `site/data/` alongside the static HTML pages:

- `site/data/wiki.json` — structured JSON (`scope`, published `sources`,
  `entries`, deduplicated `citations`, `corrections`, and `pages`)
- `site/data/entries.csv` — tabular published entries and citations (CSV)
- `site/data/sources.csv` — official source registry with URLs, SHA-256
  versions, and verified publication/access dates (CSV)
- `site/manifest.json` — SHA-256 hashes of every generated file and exact
  slice-level review decision digests

Private review deliberations, excluded/outreach-pending entries, and verbatim
`exact_quote` excerpts are never published here. Use the official URLs and
version hashes in `sources.csv` to download and independently verify every
primary record.

## Supported release profiles (`verify_public.py`)

- **`wiki-v1` (current primary profile):** Static research wiki generated by the
  private repository's offline `python3 -m compiler build-wiki` command. Permits
  only `site/index.html`, `site/search.html`, `site/style.css`,
  `site/data/{wiki.json,entries.csv,sources.csv}`, `site/topics/<id>.html`,
  `site/entries/<id>.html`, `site/sources/<id>.html`, and `site/manifest.json`
  (`mode: "public"`), with exact slice-level decision digests, output SHA-256
  verification, symlink/directory checks, and preview/synthetic marker blocking.
- **`holding-v1` / `public-v1` (legacy):** Preserved for backward compatibility.

Run `python3 -m unittest discover -s tests` and `python3 verify_public.py`
before opening a PR.
