# WhoOwnsAlberta public releases

This repository is the public release boundary for WhoOwnsAlberta.info.
GitHub Pages deploys only from protected `main` through the `deploy-pages`
workflow. The `public-artifact` job checks every PR and is required for merging.
`main` requires an independent approving review.

## Supported release profiles

- **`holding-v1`:** Temporary holding page (`site/index.html` and
  `site/manifest.json`) with a pinned SHA-256 digest in `verify_public.py`.
- **`wiki-v1` (current primary profile):** Static research wiki generated by the
  private repository's offline `python3 -m compiler build-wiki` command. Permits
  only `site/index.html`, `site/search.html`, `site/style.css`,
  `site/topics/<id>.html`, `site/entries/<id>.html`, `site/sources/<id>.html`,
  and `site/manifest.json` (`mode: "public"`), with exact slice-level decision
  digests (`factual:<scope_id>`, `publication:<scope_id>`,
  `renderer:wiki-v1-renderer`), output file SHA-256 verification, symlink/dir
  checks, and preview/synthetic marker blocking.
- **`public-v1` (legacy):** Earlier single-article/dataset profile kept for
  backward compatibility.

## Release requirements

A content release PR must replace `site/` with only the offline builder's
generated output and state the pinned private commit and SHA-256 of
`site/manifest.json`. The independent reviewer compares the proposed `site/`
tree against a build from that pinned private commit and verifies the underlying
private review decisions. Never copy raw JSON bundles, source captures, private
`exact_quote` excerpts, `exclusion_reason`s, or private Git history here.

Run `python3 -m unittest discover -s tests` and `python3 verify_public.py`
before opening a PR.
